# การเผยแพร่สื่อบน Ying Teaching Hub Web
> ฉบับเริ่มต้น 2026-11-09 | สำหรับผู้ดูแลและผู้ตรวจรับสื่อ

## กติกา
- Repository นี้เป็น **Public**: ทุกไฟล์รวมถึง JSON, ประวัติ commit และไฟล์ที่เคยถูกเพิ่มเข้ามาอาจเปิดอ่านได้
- `data/public-materials.json` ต้องมีเฉพาะสื่อที่ผู้รับผิดชอบ **ตรวจแล้ว อนุมัติแล้ว และตั้งใจเผยแพร่สาธารณะ** เท่านั้น
- อย่าใส่ชื่อจริง เลขประจำตัว รูปหน้าตา คะแนนรายคน ข้อมูลผู้ปกครอง ตารางสอนส่วนตัว รหัสผ่าน คีย์ หรือ URL ไฟล์ที่มีข้อจำกัดสิทธิ์
- แนะนำให้อัปโหลด **สำเนาสำหรับเผยแพร่** แยกจากต้นฉบับใน Drive ตรวจเปิดลิงก์จากหน้าต่างที่ไม่ล็อกอินก่อนเผยแพร่
- การที่ JavaScript กรองข้อมูลไม่ผ่านเงื่อนไข **ไม่ใช่** การปกป้องข้อมูล: ข้อมูลต้องไม่อยู่ใน Public JSON ตั้งแต่แรก
- ไม่มีระบบล็อกอินหรือแสดงคะแนนนักเรียนในระยะนี้

## รูปแบบรายการที่ยอมรับ
ข้อมูลตัวอย่าง **สมมติ** ด้านล่างมีไว้ในคู่มือเท่านั้น ห้ามคัดลอกลงไฟล์จริงจนกว่าจะมีสื่อที่อนุมัติ

```json
{
  "schema_version": 1,
  "generated_at": null,
  "materials": [
    {
      "id": "PUB-TUT-M2-U02-H04-V1",
      "title": "ชื่อใบงานที่อนุมัติ",
      "description": "รายละเอียดสั้นที่เปิดเผยได้",
      "workspace_type": "tutoring",
      "level": "ม.2",
      "subject": "คณิตศาสตร์",
      "unit": "หน่วยที่ 2",
      "version": "1.0",
      "file_url": "https://example.org/approved-public-file.pdf",
      "visibility": "PUBLIC_APPROVED",
      "approval_status": "approved",
      "publication_state": "published",
      "approved_at": "2026-11-09"
    }
  ]
}
```

## ขั้นตอนก่อนเผยแพร่
1. ผู้รับผิดชอบเปิดต้นฉบับ ตรวจความถูกต้องเนื้อหา เฉลย ลิขสิทธิ์ และข้อมูลส่วนตัวในเอกสาร/metadata
2. บันทึกการอนุมัติที่ **ระบบส่วนตัว** (อย่าใส่ข้อมูลผู้เรียนหรือครูผู้อนุมัติที่ไม่พร้อมเผยแพร่ใน Git)
3. สร้างสำเนาสื่อสาธารณะที่ไม่มีข้อมูลส่วนบุคคล และตั้งสิทธิ์ให้เปิดได้อย่างตั้งใจ
4. เพิ่มเฉพาะรายการที่อนุมัติแล้วลง `data/public-materials.json` และใช้ HTTPS URL ของไฟล์ที่เปิดเผยได้
5. รัน `node tests/validate-public-catalog.mjs` และ `node --check app.js`
6. ทำ Pull Request ตรวจทั้ง JSON/ไฟล์จริง/URL ภายนอก หากผ่านจึง Merge
7. หลังเผยแพร่ ทดสอบบนมือถือ และเปิดลิงก์สื่อจากหน้าต่างไม่ล็อกอิน

## ข้อจำกัดทางเทคนิค
- GitHub Pages เป็น static hosting และไม่ใช่ระบบจัดเก็บข้อมูลนักเรียนแบบส่วนตัว
- หน้าเว็บแสดงเฉพาะรายการที่ถูกอนุญาตใน public catalog
- หน้า Dashboard ส่วนตัว การแจ้งผลคะแนน และการเชื่อม Sheets แบบอ่าน/เขียนข้อมูลนักเรียน ต้องมี backend ที่บังคับสิทธิ์ก่อน
- ไม่มีการเรียกบริการ Google Sheets, Drive หรือ Firebase จริงใน MVP นี้
