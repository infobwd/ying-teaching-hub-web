# Ying Teaching Hub Web

เว็บไซต์สาธารณะของ **ครูหญิง — นิรมล** สำหรับเผยแพร่สื่อการเรียนรู้ที่ตรวจและอนุมัติแล้ว (Public MVP P1)

> **ไม่ใช่ระบบข้อมูลนักเรียน** — ไม่มีการเข้าสู่ระบบครู ไม่มีทะเบียนนักเรียน ไม่มีคะแนน ไม่มีข้อมูลผู้ปกครอง และไม่มีการเชื่อม Google Sheets/Drive/Firebase จริงในรุ่นนี้

## Repository แยกตามบทบาท
- **Website (Public):** `infobwd/ying-teaching-hub-web` — this repository; GitHub Pages static front end
- **Master plans (Private):** `infobwd/ying-teaching-hub` — source of truth for design, data contracts and roadmap

## มีอะไรใน MVP
- หน้าแรกภาษาไทยสำหรับมือถือและเดสก์ท็อป
- พื้นที่งานสอนประจำ / งานสอนพิเศษ (แสดงเฉพาะข้อมูลทั่วไป)
- คลังสื่อสาธารณะจาก `data/public-materials.json`, ตัวกรอง/ค้นหา/สถานะไม่มีข้อมูล
- โหมดสว่าง/มืด และเมนูสำหรับมือถือ
- หน้าบอกแผนการพัฒนา (ระบบครูส่วนตัวและคะแนน **ยังไม่เปิด**)
- ตรวจสอบไฟล์ JSON แบบ deny-by-default ก่อนเผยแพร่ด้วยสคริปต์ทดสอบ

## เริ่มใช้งานในเครื่อง
ใช้เว็บเซิร์ฟเวอร์แบบ static เพื่อให้ `fetch` JSON ทำงาน:
```bash
python3 -m http.server 8000
# เปิด http://localhost:8000/
```
ตรวจไฟล์ก่อน Merge:
```bash
node --check app.js
node tests/validate-public-catalog.mjs
```

## เปิด GitHub Pages
หลัง Merge ลง `main` ให้เข้า **Settings → Pages → Build and deployment → Deploy from a branch** เลือก `main` และ `/(root)`, Save แล้วรอ GitHub รายงาน URL หน้า Pages จากหน้า Settings/Actions ก่อนถือว่าเปิดใช้งานจริง

URL ที่คาดหมาย (ยังต้องตรวจจริง): `https://infobwd.github.io/ying-teaching-hub-web/`

## การเพิ่มสื่อที่ได้รับอนุมัติ
อ่าน [คู่มือเผยแพร่](docs/PUBLICATION_GUIDE.md) ก่อนแก้ไฟล์ `data/public-materials.json`. **อย่าเพิ่มรายการที่ยังไม่อนุมัติลงใน Public repo แม้จะตั้งค่าให้ JavaScript ซ่อนก็ตาม**

## ปลอดภัยไว้ก่อน
- ไม่มีชื่อ/คะแนนนักเรียน/ข้อมูลส่วนตัว/คีย์ หรือรหัสผ่านใด ๆ ในเว็บไซต์
- หน้าเว็บไม่ใช่ security boundary; ข้อมูลส่วนตัวต้องผ่าน backend + authorization ก่อนอนุญาตให้เข้าถึง
- งานส่วนตัวครูยังใช้แหล่งข้อมูลส่วนตัว (Sheets/Drive) ตามแผนใน Repository หลัก

## แผนผังวิชาคณิตศาสตร์ (P1B)
- เปิด `math.html` หรือกด “คณิตศาสตร์กับครูหญิง” จากหน้าแรก
- มี **ตัวอย่างผังเนื้อหา** ม.2 หน่วยที่ 2 (6 ชั่วโมง) และ ม.4 ตรรกศาสตร์ (20 ชั่วโมง) เพื่อให้สำรวจหัวข้อและเปลี่ยนชั่วโมงได้
- ข้อมูลจาก `data/public-math-outline.json` เป็นข้อมูลหัวข้อการเรียนรู้ที่จัดทำสำหรับเผยแพร่เท่านั้น **ไม่ใช่ตารางสอนจริง** และ **ไม่ใช่การยืนยันว่าใบงานมีอยู่หรือผ่านการตรวจรับ**
- สามารถเปิดลิงก์ตรงแบบ `math.html#m2-h4` หรือ `math.html#m4-h6` ได้
- ไม่มีไฟล์ชีท คะแนน รายชื่อนักเรียน ตารางส่วนตัว หรือเฉลยในผังนี้
- ข้อมูลทะเบียน/งานย้อนหลังฉบับร่างทั้งหมดอยู่ใน Repository ส่วนตัว ไม่คัดลอกมาที่นี่
- ก่อนเพิ่มเอกสารที่เผยแพร่ได้จริงต้องผ่านขั้นตอนใน [คู่มือการเผยแพร่](docs/PUBLICATION_GUIDE.md) และเพิ่มเข้าคลังสื่อสาธารณะตามเกณฑ์ที่กำหนด

## Truth Table Lab (ระยะ A–B: สื่อต้นแบบ)
- เลือก **ม.4 ชั่วโมงที่ 2 หรือ 3** บน `math.html` แล้วกด **ทดลองสื่อสร้างตารางค่าความจริง (รอตรวจรับ)** หรือเปิด `logic/truth-table.html`
- เรียนรู้ค่า T/F และตัวเชื่อม **~, ∧, ∨, →, ↔** ด้วยตารางโต้ตอบ; ใช้เครื่องสร้างตารางจากประพจน์ตัวแปร **p, q, r** พร้อมวงเล็บ คอลัมน์ย่อย และจำแนกสัจนิรันดร์/ข้อขัดแย้ง
- ใช้ **JavaScript ฝั่งเบราว์เซอร์** ไม่มีการเข้าสู่ระบบ ไม่มีคะแนนหรือข้อมูลผู้เรียน และยัง **ไม่ได้เชื่อม Supabase**
- มีตัวตรวจ `node tests/truth-table.test.mjs` และตรวจ syntax `node --check --input-type=module < logic/truth-table.js`, `node --check logic/logic-engine.mjs`; รันใน CI
- **สถานะเนื้อหา:** เว็บนี้เป็นสื่อทดลองสำหรับให้ครูหญิงตรวจรับ ไม่ใช่ชีท/แบบทดสอบที่อนุมัติเผยแพร่ และไม่เปลี่ยนสถานะ `data/public-materials.json`; ห้ามนำคลังโจทย์และเฉลยจาก Repo ส่วนตัวมาลง Public โดยไม่ได้ตรวจรับ
- ระยะ C (แบบฝึกตรวจคำตอบ) และ D–E (Supabase) ยังเป็นแผนอนาคต
